## Answers in six lines

1. **(a)** The list-recovery capacity is known for EVERY input list size ℓ ≤ q (Resch, thesis 2020, Thm 2.4.12; Resch-Yuan-Zhang 2022): rate 1 − H_{q,ℓ}(p), which for ℓ = βq is the base-q Kullback-Leibler divergence D_q(p ‖ 1−β) (mine, from their formula). But it is reached only by random, non-linear codes. Every explicit or proved-linear construction needs ℓ ≤ |Σ|^{o(1)}: Guruswami-Rudra 2008 alphabet n^{O(ε⁻² log ℓ)}; Kopparty et al. 2018 folding s ≥ 16ℓ/ε²; random linear codes q ≥ ℓ^{Ω(1/ε)} (Li-Shagrithaya 2025). Your recollection is right for constructions; the dense-list capacity is a theorem, not a gap. Worst-case negative: full-length Reed-Solomon needs R ≤ 1/ℓ at zero error (Guruswami-Rudra 2006).
2. **(b)** On the integers: list decoding of CRT codes up to the Johnson bound is claimed in polynomial time for all moduli sizes (Biasse-Quintin 2011, number-field codes, which contain Z); beyond Johnson nothing for worst-case lists. Beyond half the distance only for RANDOM errors by interleaving (Li-Sidorenko-Nielsen 2013; Abbondati-Afflatet-Guerrini-Lebreton 2023; Abbondati-Guerrini-Lebreton 2024 and 2025, the last with prime-power moduli). No statement of the integer obstruction to folding found; the mechanism for Reed-Solomon is written out by Guruswami 2008. Prime powers: the radius depends on log N only.
3. **(c)** Noisy polynomial interpolation = list recovery with random lists at zero error (Naor-Pinkas 1999; Bleichenbacher-Nguyen 2000: a lattice reduction that beats the Guruswami-Sudan condition in practice, explicit condition not obtained). The average case is a hardness assumption (Naor-Pinkas; Kiayias-Yung 2002/2008: decisional PR), stated "below √(kn)".
4. **(d)** The knapsack form is the modular multiple-choice subset-sum / average-case k-SUM over Z_m: dynamic programming O(m·Σ|L_i|), k-tree m^{1/(1+lg k)}. I found no paper on a separable-score optimisation under a modular target, and no paper on Bohr-set points with residues prescribed at many primes. (mine) For our window the DP pays only below about 11 nats, i.e. 3 to 4 primes beyond 463, which hold under 1% of the window's score variance: section 4.
5. **(e)** Beyond Swan and CCG the only forcing mechanism in the literature is the same one: inseparability, f ∈ κ[u][T^p] (T⁴ for p = 2), through the Pellet-Stickelberger-Swan formula μ(h) = (−1)^{deg h} χ(disc h). CCG say they found no mod-3 analogue. Sawin-Shusterman prove Chowla and Bateman-Horn in degree 2 for separable f and q large. The integer obstruction is stated as the parity barrier and Chowla; Conrad states the integer analogue of the CCG correction factor as "= 1", i.e. μ-sums o(x), proved only in degree 1.
6. Nothing here lowers a number of the fleet; it is vocabulary and a list of what is and is not proved.

## 1. (a) List recovery beyond the Johnson radius, and the input list size

**Definition.** (ζ, ℓ, L)-list recoverable: for input sets S_1..S_n ⊂ Σ of size ≤ ℓ, at most L codewords have c_i ∈ S_i for ≥ ζn positions (Guruswami-Rudra, IEEE-IT 54(1) 2008, Def. 5.1; ℓ = 1 is list decoding).

| statement | where | input list size |
|---|---|---|
| Guruswami-Sudan list-recovers RS codes up to radius α = 1 − √(ℓR); it needs R < 1/ℓ for any nontrivial α | KRSW18, Intro | any ℓ, but R < 1/ℓ |
| Folded RS, agreement ζ ≥ (1+δ)(ℓ R^s)^{1/(s+1)}; Thm 5.1: "for every integer ℓ ≥ 1 … (R+ε, ℓ)-list recovered in polynomial time. The alphabet size … is (N/ε²)^{O(ε⁻² log ℓ/(1−R))}" | Guruswami-Rudra 2008, §5.1, eq. (10), Thm 5.1 | log ℓ ≲ ε²(1−R)·log|Σ|/log N, i.e. ℓ ≤ \|Σ\|^{O(ε²/log N)}; list size polynomial in N |
| Thm 3.1: "folded RS code FRS_{q,s}(n,d), n ≤ (q−1)/s, 16ℓ/ε² ≤ s, is (α, ℓ, L)-list-recoverable for α = 1 − d/(sn) − ε and L = (ℓ/ε)^{O((1/ε) log(ℓ/ε))}"; same for univariate multiplicity codes of degree below the characteristic | Kopparty-Ron-Zewi-Saraf-Wootters, arXiv 1805.01498 (FOCS 2018), Thm 3.1, 4.1 | ℓ ≤ ε²s/16 = O(log \|Σ\|); constant list size |
| Random linear codes: "over alphabets of size at least ℓ^{Ω(1/ε)}, random linear codes of rate R are (1−R−ε, ℓ, (ℓ/ε)^{O(ℓ/ε)})-list-recoverable"; with Levi-Mosheiff-Shagrithaya 2024 randomly punctured RS codes too; every linear code needs L ≥ ℓ^{Ω(R/ε)} | Li-Shagrithaya, arXiv 2502.13877, Thms 1.1, 1.2, 1.5 | ℓ ≤ q^{O(ε)} |
| Earlier: Rudra-Wootters (average-radius) list size q^{O(log²(ℓ/ε))} at q ≥ ℓ^{Ω(1/ε)}; Chen-Zhang 2024: RS, FRS, multiplicity codes need list size ℓ^{Ω(1/ε)} | as cited in Li-Shagrithaya | same |

**Capacity for every ℓ.** GLMRSW (arXiv 2004.13247, Intro): "the capacity … is known to be 1 − h_q(p) for list-decoding, and 1 − log_q ℓ for list-recovery" (zero error). Resch-Yuan-Zhang (arXiv 2210.07754, Intro): "there exist (p, ℓ, O(ℓ/ε))-list-recoverable codes of rate 1 − H_{q,ℓ}(p) − ε where H_{q,ℓ}(p) := p log_q((q−ℓ)/p) + (1−p) log_q(ℓ/(1−p)); conversely, if the rate is at least 1 − H_{q,ℓ}(p) + ε then it will not be list-recoverable for any L = o(q^{εn})", for all 1 ≤ ℓ ≤ q. (mine) With ℓ = βq this is R* = D_q(p ‖ 1−β) = p log_q(p/(1−β)) + (1−p) log_q((1−p)/β): the base-q relative entropy of the agreement 1−p against the chance agreement β. It is positive iff 1−p > β, of size about ln(1/β)/ln q for β constant: **for dense lists the rate is O(1/log q) and the agreement must exceed the density.** Zero-rate threshold (RYZ, eq. (1), proved for all ℓ, L, q): p_*(q,ℓ,L) = 1 − (1/L)·E[pl_ℓ(X_1..X_L)], X_i uniform on [q], pl_ℓ the top-ℓ plurality; (mine) → 1 − ℓ/q as L → ∞.

**Negative results (worst case).** Guruswami-Rudra 2006 (as described in Li-Shagrithaya, §1.1): "in the setting of zero-error list-recovery (ρ = 0), many full length Reed-Solomon codes of rate R require R ≤ 1/ℓ in order to have poly n output list size". (mine, from memory of that paper's construction, not re-read: the input sets are subfields of F_q.) Random linear codes at rate 1 − log_q ℓ − ε need L ≥ ℓ^{Ω(1/ε)} (GLMRSW). **On average (random lists, a fixed algebraic code): nothing proved that I found; the only algorithm is Bleichenbacher-Nguyen's (section 3).**

## 2. (b) The integer side: CRT codes

- Code: x < B ↦ (x mod p_1, …, x mod p_n), p_i coprime. **Goldreich-Ron-Sudan** (STOC 1999; IEEE-IT 46(4) 2000, venue from memory): polynomial list decoding for e < n − √(2kn log p_n / log p_1) (as quoted by Boneh). **Boneh** (JCSS 64 (2002) 768-784; STOC 2000): "Our new algorithm achieves the stronger bound e < n − √(kn log p_n / log p_1) … The bounds we obtain are identical to the bounds obtained by Guruswami and Sudan for Reed-Solomon list decoding" (abstract; B = ∏_{i ≤ k} p_i). **Guruswami-Sahai-Sudan** (FOCS 2000): soft-decision (weighted) version.
- **Biasse-Quintin** (arXiv 1107.2321, 6 pp.): "a direct adaptation of an analogue of Coppersmith's theorem due to Cohn and Heninger allows to follow the approach of Boneh which does not allow to reach the Johnson bound. Then we adapt the decoding paradigm of [Guruswami's thesis, Chap. 7] … to achieve the Johnson bound." Thm 1: all messages with ‖m‖ ≤ B = ∏_{i≤k} N(p_i) and agreement t ≥ √(k(n+ε)), polynomial in d, log N, 1/ε, log|Δ|; K = Q is allowed (d = 1) (mine). Weighted form, Prop. 1: Σ a_i z_i log N(p_i) ≥ √(log(2d²B^d) Σ z_i² log N(p_i) + ε z_max²). The proofs are sketched in a conference-length paper; I did not verify them.
- **Cohn-Heninger** (arXiv 1008.1284, ICS 2011): Coppersmith's theorem, Guruswami-Sudan and number-field/ideal versions are one theorem; "multivariate versions of Coppersmith's theorem correspond to list decoding of Parvaresh-Vardy and Guruswami-Rudra codes"; and "the problem of determining whether there is a root in an arbitrary given interval is NP-complete" for a modulus with many prime factors.
- **Beyond Johnson, random errors only**: interleaved CRT codes: heuristic failure analysis Li-Sidorenko-Nielsen (ISIT 2013, pp. 1052-1056), rigorous Abbondati-Afflatet-Guerrini-Lebreton ("Probabilistic analysis of LLL-based decoder of interleaved Chinese remainder codes", ITW 2023), rational numbers Abbondati-Guerrini-Lebreton (ISSAC 2024, pp. 153-161), with multiplicities and bad primes Abbondati-Guerrini-Lebreton, arXiv 2504.08472: "if R is C plus a random error of weighted Hamming distance up to approximately ℓ/(ℓ+1) log(N/(2FG)) … this decoder is able to decode most of the time"; "Note that, a decoding algorithm working under this latter approach must inevitably fail for some instances, as beyond unique decoding radius there can be many codewords around a given instance." The integer counterpart of interleaved RS codes (Schmidt-Sidorenko-Bossert 2009).
- **List decoding beyond Johnson on Z, worst case**: I found none. **The obstruction**: not stated for Z in any paper I found. The mechanism it would have to replace is written out for RS by Guruswami (arXiv 0811.4139, STOC 2009): "the identity f(γT) ≡ f(T)^q (mod (T^{q−1} − γ)), and the fact that (T^{q−1} − γ) is irreducible … a low-degree algebraic relation between f(T) and f(γT)"; "The crucial insight … was the fact that this additional function could just be … the image of f(T) under the automorphism T ↦ γT"; folding "arise[s] out of the Artin-Frobenius automorphism at primes in Galois extensions", with a footnote comparing cyclotomic number fields (ζ ↦ ζⁿ) and the remark that for Q(ω) "this theory is well developed". Guruswami-Xing (STOC 2012) say an automorphism playing the role of f(X) ↦ f(γX) is known only for very special function fields; the 2013 follow-up needs only suitable places (both from search abstracts, not read). (mine) Z has no non-trivial ring automorphism and the Frobenius of Z/p is the identity, so no relation links N mod p and N mod p'; the candidate substitute is a cyclic Galois extension K/Q (cyclotomic), with messages in O_K. I found no paper that builds or decodes a folded number-field code.
- **Prime powers.** The CRT code with moduli p_j^{λ_j} is a CRT code with coprime moduli; the decoding radius in Abbondati et al. (Eq. (5), Thm 2.18) depends on N = ∏ p_j^{λ_j} through log N, and their stated gain from multiplicities is speed: "solving a linear system modulo p^λ is asymptotically faster than solving it modulo p_1, …, p_λ". I found no result in which prime-power moduli enlarge the list-decoding radius. (mine) The multiplicity-code gain over RS comes from the derivatives f, f', … being independent algebraic functions of one polynomial; the digits of N modulo p^s are related by carries, not by a derivation (Buium's p-derivations are not additive), so the linear-algebraic step of multiplicity-code decoding has no obvious integer form.

## 3. (c) Noisy polynomial interpolation and noisy Chinese remaindering

- **Problem** (Bleichenbacher-Nguyen, Eurocrypt 2000, LNCS 1807, pp. 53-69; Nguyen's Stanford seminar abstract): "Let P be a k degree polynomial over a finite field F. Then given n > k+1 sets, each containing m−1 random elements and one element which is the value of P at a known point, the problem is to recover the polynomial P, provided that the solution is unique." Introduced by Naor-Pinkas (STOC 1999) "for oblivious polynomial evaluation". (mine) This is zero-error list recovery with random lists of size m; Guruswami-Sudan needs n ≥ km (R < 1/ℓ, above); uniqueness needs about n > k ln q/ln(q/m).
- **Algorithm**: "a reduction from noisy polynomial interpolation to the lattice shortest vector problem, when the parameters satisfy a certain condition that we make explicit. Standard lattice reduction techniques appear to solve most of the practical instances … noisy polynomial interpolation is much easier than expected." The noisy CRT version is "related to the problem of Chinese remaindering with errors". **I could not obtain the full text (the only link is ftp; Springer is paywalled), so the explicit condition and the cost as a function of m and n are not read here.**
- **Hardness use**: Naor-Pinkas (OPE); Kiayias-Yung (ECCC TR02-017, ICALP 2002; a revised journal version is ePrint 2007/153, IEEE-IT 2008, venue from memory): PR = "Given n points over a (large) finite field F, such that at least t of them belong to the graph of a polynomial p of degree less than k, recover such a polynomial"; Berlekamp-Welch at t ≥ (n+k)/2, Guruswami-Sudan at t ≥ √(kn) "(many solutions are possible in the worst case). The current state of knowledge suggests that for values of t below √(kn) the problem is hard."; they assume a decisional version (DPR: tell an error location from a non-error location) and prove partial-information hiding and pseudorandomness of PR instances under it. This is an average-case (random noise) assumption. Their Asiacrypt 2004 paper (title as I recall it, on the Augot-Finiasz PR-based public-key system) I could not read.

## 4. (d) Bohr sets, and the knapsack form

- **Your formulation is standard.** The residue vector (x_r) ∈ ∏ Z/r is the integer N = Σ x_r e_r mod P, and N/P = Σ_r {x_r u_r/r} (mod 1), u_r = (P/r)^{-1} mod r, so N < X means one character lies in an arc of length e^{-D}, D = ln(P/X) (mine, a check of your statement). With a separable score it is a **multiple-choice subset-sum with a modular target** (one item per prime), the **average-case k-SUM over Z_m** (k lists), or "CRT decoding with a size constraint" (Boneh's name for the unscored version).
- **Exponents.** Bellman's dynamic programming O(m · Σ|L_i|) = e^D · Σ r; modular subset sum in Õ(m), matching a SETH lower bound (Axiotis-Backurs-Tzamos, arXiv 1807.04825: "an algorithm running in time Õ(m), which matches a recent conditional lower bound of [ABHS17] based on the Strong Exponential Time Hypothesis"). Average case: Wagner's k-tree "succeeds with constant probability if n ≈ m^{1/(log k+1)}, and … runs in time O(kn)" (Lin-Vasudevan, arXiv 2410.06856, abstract; also over Z_m); extended k-tree (Minder-Sinclair, J. Cryptology 2012) for smaller lists, not read; random subset-sum Õ(2^{0.291n}) (Becker-Coron-Joux 2011), Õ(2^{0.283n}) (Bonnetain-Bricout-Schrottenloher-Shen, arXiv 2002.05276). Classical text for the multiple-choice knapsack: Kellerer-Pferschy-Pisinger, Knapsack Problems (2004), not read.
- **Not found**: a separable-score optimisation under a modular target (the "score" version), average-case exponents for it, and anything on Bohr-set points with prescribed residues at many primes. For small rank the standard tool is lattice reduction (simultaneous Diophantine approximation: Lenstra-Lenstra-Lovász 1982; Bosma-Smeets 2013), not read.
- **(mine) What the DP reaches in the actual problem** (`data/bottomup/` computation in this session, window of one cover vector K = 2.2·10⁷ = e^{16.9}, 1,300 alive rows, strike variance n/r per prime, linearised): primes in (463, 10³] hold 10.3% of the window's score variance, (10³, 10⁴] 26.2%, (10⁴, 10⁵] 20.4%, (10⁵, 10⁶] 16.7%, (10⁶, 10⁸] 26.4%. The DP with D = 20 nats (5·10⁸ states) takes 5 primes beyond 463 (467 to 499) and sees 0.95% of the variance; D = 30 nats (10¹³ states) 7 primes, 1.3%. Enumerating the partial score of the K = e^{16.9} members costs about K·|primes| ≈ 10⁸ operations, the DP e^D·Σr ≈ 10¹² at D = 20 (5 primes of size 480): the DP wins only for D below about 11 nats (3 to 4 primes, 0.76% of the variance), so it never beats the window enumeration the fleet already does. For the cover the score is a coverage function (a row is killed once however many primes strike it), not a sum over primes, so the form does not apply.

## 5. (e) The function-field non-analogy

- **Swan** (Pacific J. Math. 12 (1962), not read; via Bluher, CCG): over F_2, trinomials x^{8k} + x^m + 1 (8k > m) have an even number of irreducible factors, so are reducible; the parity of the number of factors of any squarefree trinomial is determined. **Stickelberger-Pellet-Swan**: for odd characteristic, Conrad 2005 Lemma 4.1: "μ(h) = (−1)^{deg h} χ(disc_κ h)"; for characteristic 2 a Witt-vector formula (Swan). Conrad: "unlike the case over Z, there is another formula for the Möbius function in κ[u], and this does not require factoring."
- **Bluher** (arXiv math/0406538): for odd n and f = x^n + Σ_{i∈S} x^i + 1 over F_2 with S ⊂ {odd i < n/3} ∪ {i ≡ n mod 4}: n ≡ ±1 mod 8 gives an odd number of irreducible factors, n ≡ ±3 mod 8 an even number.
- **Conrad-Conrad-Gross**, Prime specialization in genus 0 (Trans. AMS 360 (2008) 2867-2908): "the natural analogue of this conjecture … is not generally true when f(T) is a polynomial in T^p. The explanation rests on a new global obstruction which can be measured by an appropriate average of the nonzero Möbius values μ(f(g)) as g varies … has a periodic behavior governed by the geometry of the plane curve f = 0." Thm 4.4 (Conrad's survey): for f ∈ κ[u][T^p] (p odd) or κ[u][T⁴] (p = 2), μ(f(g)) depends only on g mod M, deg g mod 4 and the character of the leading coefficient. Examples: T^{4q} + u^{2q−1} is reducible at every g; T⁴ + u over F_2[u] has prime values only in odd degree; the ratios of the true count to the naive one tend to periodic limits with period 1, 2 or 4. "While the classical conjectures … involve only local obstructions, the Möbius average in the κ[u]-setting is a fundamentally global obstruction. The Möbius function could be considered as a 'parity' obstruction … We have not found a role for a similar type of obstruction … based on the number of irreducible factors … counted modulo 3 or higher." Conrad: "a new global obstruction that has no known counterpart in characteristic 0"; "We expect that the Naive Conjecture is correct if f(T) ∉ κ[u][T^p], but we have not proved anything in that direction."
- **Sawin-Shusterman** (Annals 196 (2022), arXiv 1808.04001): twin primes for p odd and q > 685090 p² (their Thm 1.1), "the main ingredient … is the removal of the 'parity barrier'", i.e. Chowla's k-point conjecture over F_q[T] for q > p²k²e²; Remark 1.2: the proof gives the Goldbach problem over function fields and more general linear forms. Sawin-Shusterman (Invent. Math. 229, arXiv 2008.09905): Bateman-Horn in degree 2 for q > 2^{10}3²e²p⁴, Chowla for separable F of degree k in T for q > 4e²k²p² ("complements [CCG08] which deals with certain squarefree inseparable polynomials F, for which Eq. (1.7) is shown not to hold"); "inseparable polynomials over F_q[u], a family of polynomials that does not have a counterpart over Z". Large-q fixed-degree versions: Entin 2016/2018, Kowalski 2016 (cited there; not read).
- **The structure they use, and its integer comparison** (SS19, §1.2-1.3): "for any fixed polynomial r, the function μ(r + s^p) essentially equals χ_{D_r}(s + c_r) where χ_{D_r} is a quadratic Dirichlet character and c_r is a shift, both depending only on r (and not on s)": on the affine subspaces r + {s^p} the Möbius function IS a Dirichlet character, because d/dT(r + s^p) = r' does not depend on s and Pellet's formula turns μ into a character of a resultant; "very closely related to the properties of Möbius described in [CCG08]". "Over the integers, the k = 2 case of the Chowla conjecture, with logarithmic averaging, was proven by Tao [Tao16] building on Matomäki-Radziwiłł; the k odd case, again with logarithmic averaging, was handled by Tao and Teräväinen" (their words, 2019). Nothing comparable to the subspace structure exists over Z (mine: Z has no Frobenius, hence no p-th-power subspaces on which μ is a character).
- **The integer side.** Sawin-Shusterman, 2020: "One of the difficulties in making progress on the Bateman-Horn conjecture is the parity barrier, or in other words, producing many integers n with F(n) having an odd number of prime factors" (implicit in Iwaniec 1978); Chowla 1965: Σ_{n≤X} μ(F(n)) = o(X) for squarefree F ∈ Z[T], "the only resolved case is the linear one". Conrad 2005 states the integer analogue of the CCG correction factor as 1: Σ_{n≤x} μ(f(n))/x → 0 for irreducible non-constant f with a squarefree value (equivalent to the version over squarefree values unconditionally for deg ≤ 3, under abc beyond); "For other f of degree 1, (7) is equivalent to Dirichlet's theorem. No other case of (7) has been proved." So the sharpest integer statement in the literature is: **no global parity bias at all (the Möbius average is 1), unproved beyond degree 1; the function-field forcing exists exactly where f is inseparable, which has no integer counterpart.** For Goldbach (linear forms N − P) no inseparable polynomial occurs, and the function-field Goldbach problem is proved for large q (Sawin-Shusterman, Remark 1.2).
