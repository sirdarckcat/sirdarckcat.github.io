# Mechanism scoring on the exact miniature (helper session)

Companion data for `../../MECHANISMS.md`. Everything here is reproducible on a 4-core machine with 16 GB; the per-member arrays (1–4 GB per miniature) are regenerated by `mini` and not committed.

## Build

    gcc -O3 -march=native -fopenmp -o mini    mini.c
    gcc -O3 -march=native -fopenmp -o evalN   evalN.c  -lm
    gcc -O3 -march=native -fopenmp -o bayes   bayes.c  -lm
    gcc -O3 -march=native -fopenmp -o nbr4    nbr4.c           # the deduplicated neighbour search quoted in the note
    gcc -O3 -march=native -fopenmp -DNW=8 -o nbr5w nbr5.c -lm   # success-mass model (dropped, see the note)

## The miniatures

    ./mini 1000000000 1000 A      # A: X = 1e9, Q = 1000   -> A.idx.u32 (N/2), A.k.u8 (6 bytes per N: rows alive after odd primes <= 23, 31, 43, 61, 97, 199), A.s.u8 (success flag)
    ./mini 2000000000 1000 B      # B
    ./mini 1000000000 900  C      # C

`lib.py` (+ `ev.py`) holds the evaluation: Research's interpolated cost-to-k convention, the paired bootstrap over success sets, the logit fit.

## Mechanisms -> scripts -> logs (in `logs/`)

| mechanism | script | log |
|---|---|---|
| M1 size | `m1_size.py` | `m1_size_ABC.log` |
| M2 Bayes bound | `bayes.c`, `bayes_an.py` | `bayes_bound_A.log`, `bayes_bound_B.log` |
| M3 funnel | `funnel.py`, `funnel_eval.py`, `funnel_b.py` | `funnel_fit_A.log`, `funnel_out_of_sample_BC.log`, `funnel_b_A.log` |
| M4a success-seeded neighbours | `nbr.py` | `neighbours_success_seeded_ABC.log` |
| M4b near-success-seeded neighbours | `nbr4.c`, `nbr4_drive.py` (`nbr2.c`, `nbr3.c` and their drivers are earlier variants without deduplication) | `nbr4_A.log`, `nbr4_A_J_cmin_grid.log`, `nbr4_B.log`, `nbr4_C.log` |
| M4b over Q | `qscale.py` | `qscale_Q700-1100.log` |
| M5 squares | `fam.py`, `fam_gen.py`, `evalN.c`, `sq_family.py` | `squares_family_A.log` |
| M6 coherence | `evalN.c`, `coh_run.py`, `fam_blk.py`, `fam_blk2.py` | `coherence_index_ABC.log`, `block_family_{A,B,C}.log` |
| M7 N/2 prime | `half_prime.py` | `half_prime_ABC.log` |

`make_logs.sh` regenerates the small logs from the per-member data.

## Caveats on the code

- `ev.py`'s `cost_interp` reproduces Research's `toy_compare.py` on A to the digit; the bootstrap is mine.
- `mini.c` stops at 192 rows (Q < about 1180).
- `nbr4.c` counts a neighbour once however many seeds reach it, and skips neighbours that are already in the stream prefix; that is why its counts are lower than `nbr3.c`'s.
